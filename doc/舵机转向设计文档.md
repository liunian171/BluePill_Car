## 0. 安全铁律（优先级高于一切功能）

1. **上电默认中位**：初始化完成前舵机必须先输出中位（直行位）
2. **软件限幅**：所有角度指令（文本/二进制/后续巡线）写入前一律 clamp 到 `[SL, SR]`（左/右标定限位）
3. **标定前保守默认**：限位未标定时软件限幅 **中位 ±10°**
4. **STOP 回中位**：急停时前轮回直行位
5. **大幅动舵机前提**：脱开转向连杆或前桥悬空；标定探索只用 ±1° 微步

## 3. 命令域定义（2026-09-09 修订：命令 = 输出域绝对角）

> 修订原因：SS2 复测发现"相对直行域 + SC 叠加"与用户实测的绝对角语义双算（SV -90 被算成 -180 → clamp 到 -115）。
> 实测直行位在 -90（机构安装偏 ~90°），**命令域直接采用输出域绝对角**，SC 不再叠加、只作上电/STOP 的回正目标。

**命令角度 = 输出域绝对角（由 SS2 实测标定）**：

| 位置 | 输出角 | 舵机脉宽 | 占空比 |
|------|-------|---------|--------|
| 右满舵（下限 SL） | **-115** | 648µs | 3.24% |
| **直行** | **-90** | 833µs | 4.17% |
| 左满舵（上限 SR） | **-65** | 1019µs | 5.09% |

- 行程 ±25（对称）；`SV 0` 在行程外 → clamp 到左满舵 -65（正常现象，域内没有 0）
- ⚠️ 方向备忘：指令正向（朝 -65）= 用户标"左"——摆臂偏装且方向与常规相反，SS3 转向模型统一符号

**命令清单（无线文本，沿用现有风格）**：

| 命令 | 作用 | 应答 |
|------|------|------|
| `SV <deg>` | 设转向角（输出域绝对角，clamp 到 [-115, -65]） | `SV:xx.x` |
| `SV+` / `SV-` | ±1° 微步 | `SV:xx.x` |
| `SL <deg>` / `SR <deg>` / `SC <deg>` | 下限/上限/直行位（标定参数，RAM 生效） | 回显 |
| `MS <rpm>` | **双电机同步转速**（M0=M1，手动指令优先退出巡线） | `MS:60RPM` |
| `STOP` | 急停 + 前轮回直行位（-90） | `STOP OK` |
| 二进制 0x10 `AA 10 <id> <float 角度> FF FF` | 同 SV（有线协议保留） | `SV:xx.x` |

## 6. 执行组件 steering 契约（2026-09-11 建立，commit `aa7b70b`）

> 定位：把原先锁在 `main.c` 的舵机命令域（行程限位 + 域换算 + 状态）搬进执行组件层。
> 依据：`doc/舵机代码结构对照分析.md` §3 三问判定 / §4 钳位归层 / §6 决策结论。

### 6.1 接口契约（单位与坐标域 = 义务 8）

| 接口 | 单位 / 域 | 语义 | 错误行为（义务 6） |
|------|----------|------|------------------|
| `steering_init(cfg, out)` | cfg 为标定值表；out 为输出注入 | 注入配置与输出通道，并按 center 归位一次 | 非法配置 → `BAD_CFG`，**不置初始化位** |
| `steering_set(angle)` | **输出域绝对角**(°) | 意图角 → 行程钳位 → 下发 | 未初始化 → `NOT_INIT`；越界**钳位保底**并生效（属正常语义） |
| `steering_nudge(±d)` | 输出域增量(°) | 当前角 ± d | 同上 |
| `steering_center()` | — | 回直行位（上电 / STOP） | 未初始化 → `NOT_INIT` |
| `steering_set_limit_min/max(v)` | 输出域(°) | **配置态**：设置行程限位 | 超 `lim_abs` → `BAD_ARG`（仍钳位保底）；min>max 自动交换 |
| `steering_set_center(v)` | 输出域(°) | **配置态**：设置直行位 | 超限位或超 `lim_abs` → `BAD_ARG`（仍拉回区间） |
| `steering_get()` | 输出域(°) | 当前生效角（钳位后） | 不适用 |
| `steering_output_fn(id, phys)` | **物理角**(°) | 组件 → 器件侧的唯一出口 | 由组装层绑到 `servo_bridge_set_angle` |

### 6.2 坐标域与换算（本车标定）

| 位置 | 输出域(°) | 物理角(°) | 脉宽(µs) | 占空比 |
|------|:---:|:---:|:---:|:---:|
| 右满舵（下限 SL） | -115 | 20 | 648 | 3.24% |
| **直行** | **-90** | **45** | **833** | 4.17% |
| 左满舵（上限 SR） | -65 | 70 | 1019 | 5.09% |
| 器件行程两端 | — | 0 / 270 | 500 / 2500 | 2.5% / 12.5% |

换算：`物理角 = 输出域角 + 135`（135 = 电气中位，也是**安装偏置**，属车知识 → 归本组件配置而不是执行对象层）。

> **语义确认（2026-09-11 用户）**：`[-115, -65]` 是**阿克曼前轮结构的机械可达范围（两个方向的转向极限）**，`-90` 是直行中位、落在该范围之内（不在端点）。即所谓"限位"是**结构本身能给到的转向幅度**，不是电气限位；因此它是"车知识"，与器件行程（0~270°）是两回事——这也正是 §6.3 三层钳位要分开的原因。

### 6.3 三层钳位（各管各的域，不算重复）

| 层 | 钳位对象 | 数值 | 知识类型 | 作用 |
|----|---------|------|---------|------|
| `steering` 组件 | **机构行程**（输出域） | [-115, -65] | 车知识（标定） | 正常路径第一道，**唯一所有者** |
| `Servo` 执行对象层 | **器件行程**（物理角） | [0, 270] | 器件知识 | 兜底——任何调用路径都绕不过 |
| `PWMServoProtocol` 器件层 | **器件脉宽** | [500, 2500]µs | 器件知识 | 兜底最底层 |

### 6.4 main.c 集成位置（只动这几处，均在 USER CODE 区）

| 位置 | 内容 |
|------|------|
| ① PV 区 | `g_steering_cfg` 标定表（lim_min/max/center/phys_offset/lim_abs/servo_id）+ `steering_output_to_servo()` |
| ② init 区 | `servo_bridge_init/start` → `steering_init`（失败 `Error_Handler`）→ `steering_center()`；**在巡线 init 之前**（安全铁律） |
| ③ 命令分发区 | `SV`/`SV±`/`SL`/`SR`/`SC`/`STOP`/二进制 `0x10` → `steering_*`；回显一律取 `steering_get()`（钳位后实际值） |
| ④ 50ms 控制区 | **暂无**（转向未参与闭环）；T1 转向模型接入时在此调用 |
| ⑤ 显示区 | 无（OLED 未占用转向页） |
