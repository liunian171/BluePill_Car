# IMU 调试 SOP — yaw/姿态链路调试标准流程

> 版本: v1.0 (2026-09-15)。基于 IMU-1 yaw 失真专案全流程实跑验证（PC 仿真 → E 系列真机实验 → 门限修复 → 复验闭环）。
> 定位: 本工程操作规范；方法论与 PID 调参 SOP（`doc/调参SOP.md`）同构。

---

## 1. 工具链总览

| 工具 | 通道 | 用途 |
|------|------|------|
| `ITEL 2`（VOFA+ FireWater） | 7 通道真实物理量：gx/gy/gz(°/s)，roll/pitch/yaw(°)，driftz(°/s) | 实时目视曲线（本 SOP 默认通道） |
| `ITEL 1`（CSV 9 列） | tick,gx10..yaw10,stable,driftz100 | PC 脚本机读 |
| `tools/imu_turn_test.py` | COM 口 + 前置命令参数 | 90° 转角协议化定量分析（三指标 + 陀螺侧积分交叉验证） |
| `tools/imu_sim_verify.py` | 纯 PC | 改算法前先仿真复现/验证（真机实验前的理论预演） |
| 在线命令 | `IGAIN`/`IDRIFT`/`IRATE`/`ICAL` | 参数注入与二分开关 |

## 2. 标准实验流程（转角测试）

1. **连接**：VOFA+（FireWater/9600）或 `imu_turn_test.py <COM>`；车平放桌面
2. **校准**：发 `ICAL` → 静置 5s（50 拍采零偏 + 四元数重初始化，yaw 归零）
3. **激励**：原地匀速转 90°（8~10s，平稳别晃——手持晃动会破坏静止判据干扰实验）
4. **观察**：停转后静置 15s 看回落，再静置 1min 看漂移
5. **判读三指标**：跟随角（应 ≈ 实际转角 ±10°）/ 回落量（<5°）/ 静置漂移（<1°/min）

## 3. 诊断决策表（ITEL 2 曲线怎么读）

| 现象 | 指向 | 处置 |
|------|------|------|
| driftz 在转动中爬平台（如 -5.5）且 yaw 跟不满、停转回落 | 漂移跟踪误吸收旋转 | 门限修复已内置（1.5°/s）；复现则查 `IDRIFT` 状态与固件版本 |
| yaw 跟满但停转后缓慢线性漂（~0.1-0.2°/s） | 残余零偏无补偿（IDRIFT 0 的代价） | 恢复补偿（默认开）；或 `ICAL` 重校 |
| 静置漂移 >1°/min | 启动校准时车没静稳 / 温漂 | `ICAL` 重校（静稳前提下）；仍大 → 查陀螺健康 |
| 转动中 gx/gy/gz 全变 0.00 且姿态冻结 | **I2C 读失败帧**（固件置零+跳过融合） | 查排线/供电；剧烈晃动时出现属排线抖动嫌疑（观察项） |
| 快甩时 yaw 明显少跟 | 陀螺 ±250°/s 饱和 或 10Hz 采样漏角 | `IRATE 50` 对照；仍差 → 量程提档（需改器件配置，动 .ioc 前问用户） |
| yaw 阶梯状跳变 | I2C 间歇失败 / 帧丢行 | 无线链路换 `imu_turn_test.py` 机读；有线直连复查 |

## 4. 二分实验序列（新症状启用）

按序隔离，每步只动一个变量（前置命令用 `\|` 分隔发给 `imu_turn_test.py`）：

```
E1  基线                → 确认症状 + 三指标基线
E1b "IDRIFT 0"          → 漂移补偿嫌疑（本次 IMU-1 即此路径命中）
E2  "IGAIN 0 0|IDRIFT 0" → Mahony 修正项嫌疑（纯陀螺积分）
E3  "IRATE 50"          → 采样率嫌疑（快转漏角）
E4  看快甩 gz 原始值      → 量程饱和（贴 ±250°/s 即中招）
```

**方法论**：改动算法前先跑 `imu_sim_verify.py` 仿真复现症状 + 验证修法，真机只做终审（本次 IMU-1 一次命中零返工的关键）。

## 5. 踩坑速查

| 坑 | 规避 |
|----|------|
| 转车用手持晃动 | 加速度模值波动破坏静止判据，实验数据作废——桌面原地平稳旋转 |
| pyserial `readlines()` 在 BT04 链路无声挂死 | 采集脚本一律 `read()` 分块按 `\n` 切（imu_capture/imu_turn_test 已固化） |
| newlib-nano 浮点打印 | FireWater 行用 `fmt_f2` 整数拆分（main.c），禁 `%f` |
| ITEL 模式 1/2 同时开 | 双份流量 ~450B/s 超 9600 预算一半——二选一 |
| 实验完忘恢复参数 | `IDRIFT 1` / `IGAIN 50 0` / `IRATE 100`（复位也可全恢复） |
