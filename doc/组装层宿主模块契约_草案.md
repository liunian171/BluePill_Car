# 组装层宿主模块契约（app_*）—— 草案待评审

> 创建: 2026-09-20。状态: ⬜ **草案**（契约先行：本文档 + 6 个纯 .h 头文件，零实现、不进编译链，评审通过后才开始动 main.c）。
> 背景: main.c 1345 行上提为装载器、组装层拆为 app_* 模块，为接入 FreeRTOS 预留（会话讨论 2026-09-20，用户意向）。
> 判据来源: 代码风格指南 §1.2（脑干模型）/ §4.3（五位置）/ §4.2 义务 8 项 / §7（死代码纪律）；桥接层家族契约（返回码家族）。
> 头文件落盘: `Core/Inc/app/`（app_iface / app_link / app_control / app_display / app_tx / app_wiring）——**当前无任何文件 include 它们，CMake 不受影响**。

---

## 1. 定位与铁律（不破坏现有模型）

1. **app_* 模块仍是组装层（脑干）**：职责仍是"节拍接线 / 接管权仲裁 / 生命安全 / 感官呈现"，只裁决不思考。拆文件 ≠ 升层级。
2. **main 升为装载层**：只做 CubeMX init + `app_wiring_load()` + 启动调度（裸机 while / 将来 RTOS 创建任务）。目标 ≤150 行。
3. **"新能力 = 新决策组件"铁律不变**：app_* 永远不收编业务逻辑；line_follower/speed_loop 等组件层**零改动**（RTOS 化的主要收益来源）。
4. **car_config.h 唯一 include 者 = app_wiring**（组装层配置单规则 §4.5 顺延；装载层也不 include）。

## 2. 模块清单（对应 main.c 现块的搬迁映射）

| 模块 | 职责（一句话） | 吞掉 main.c 现块 | 约行数 |

## 4. 接口带（跨模块通道，全部函数指针结构体，wiring 负责填）

| 接口 | 方向 | 语义要点 |
|------|------|---------|
| `app_tx_sink_t` | link/tx → 出口 | 应答与遥测的唯一发送入口；`send(buf,n,ctx)` |
| `app_page_note_t` | link → display | OLED 页4（应答）/页6（命令）喂数；实现侧负责 ≤19 字符截断 |
| `set_active(link)` | link → tx | 每条命令执行前登记来源链路（应答路由依据） |
| `owner_link()` / 会话锁 / `wd_feed` | link → tx/control | 指挥权查询（含 P3 编号换算）、`BUSY:SESSION` 判据、owner 字节喂狗 |
| `usb_alive()` | wiring → control | 判活三信号（dev_state + pClassData + DTR），HAL 读收敛在 wiring |
| 意图缓冲 | line_follower → control | 现有 `g_lf_tgt/g_lf_dir` 收编为 app_control 私有缓冲，指针传给 `line_follower_update`（行为不变） |

## 5. 各模块契约要点（详细以 .h 注释为准）

- **app_link**：`init(cfg, io)` 校验全失败返回码；`task(now)` 每轮每链 ≤ cfg.byte_budget 分片消费（§4.4 口径）；门控 = 非 owner 仅 STOP/PING/LINK(+0xF0) 放行，会话期 LINK 回 `BUSY:SESSION`；**接管权收敛（顺带兑现 C4）**：命令表每项标 `manual` 属性，=1 的命令执行前由 task 统一调 `io.override_manual()`（替代现散落的 11 处 `line_follower_enable(0)`，语义等价：均为执行前调用）；ISR 侧只提供 `uart_rx_isr/usb_rx_isr(byte)` 两个注入函数（**顺带兑现 P1-8**：usbd_cdc_if 的 `extern g_ringbuf_usb` 改为经注册 sink 调 app_link）。
- **app_control**：调参工具链状态机（STEP/TEL/REC/ITEL）与 ODOM 开关全部私有化，公开 `step_start/tel_set/rec_dump/odom_set/...` 供 app_link 命令调用——**消除现 g_step_active 等 6 个跨块共享标志**；`stop_all()` = STOP/WD 共用的急停收口；`session_active()` 供仲裁会话锁；WD 判定在 task 内（闩锁语义不变）。
- **app_display**：8 页轮转 + 熔断逻辑原样搬迁；健康数据经 io getters（owner 字符串 / USB 状态 / ringbuf 溢出和）；`note_cmd/note_resp` 公开仅供 wiring 绑定。
- **app_tx**：两个原始出口（USB 非阻塞 + 10ms BUSY 上限；UART 阻塞 100ms）原样搬迁，链路禁用 = no-op（P3 语义不变）；`owner_main_link()` 编号换算唯一实现点。
- **app_wiring**：20 宏 → cfg 值的唯一翻译点；init 顺序 = 现装载顺序（失败 → 返回错误码，装载层 Error_Handler，"init 失败即停"语义不变，真机已验 §22）。
- **错误通道**：全部返回 `bridge_ret_t`（家族契约顺延）；取值类 io 返回头文件注明的安全默认值；热路径显式 `(void)`。
