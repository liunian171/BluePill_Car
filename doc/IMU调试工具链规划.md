## 1. 与 PID 工具链的模式对照（方法论来源）

PID 工具链（2026-09-13，TL-1~TL-6）跑通的套路，IMU 逐项对齐：

| 环节 | PID 工具链做法 | IMU 工具链对应 |
|------|---------------|---------------|
| 前置修复 | P0-1 抗饱和 / P0-2 带符号测速（先修后测，数据才可信） | 先隔离 yaw 污染源（§3 实验 E1/E2），再谈整定 |
| 固件·下发 | `P<id>` / `FF` / `0xE0` 在线改参 | `IGAIN`（Mahony Kp/Ki）+ `IDRIFT`（漂移补偿开关）+ `IRATE`（更新周期） |
| 固件·遥测 | `TEL` 10Hz CSV + `STEP` 阶跃 CSV | `ITEL` 姿态遥测 CSV（分频可调） |
| 固件·机内记录 | `REC/DUMP` 20Hz 写 RAM + 匀速重放 | 复用同模式（IMU通道小缓冲，或扩展现有 REC 加通道位） |
| PC 工具 | bt_connect / step_capture / step_ident / ab_step | 复用 bt_connect；新增 imu_capture / imu_turn_test / imu_analyze |
| 验证闭环 | A/B/C 消融对照 + 量化指标 | 转 90° 协议化：跟随角 / 回落角 / 静置漂移三个量化指标 |
| 资产化 | 参数回写默认 + SOP + commit | 结论回写 imu_bridge 默认参数 + 调试总结 §20 收口 + commit |
| 结构收尾 | C2 speed_loop 组件抽取（工具链先行→结构后搬） | C3 姿态组件下沉（胖桥 ~90 行→感知组件），工具链先行同理 |

**顺序铁律沿袭**：先修数据可信（隔离污染源）→ 再建观测（遥测/记录）→ 最后动结构（C3）。与 §7.2"先 C2 反而更慢"同理由：先 C3 再查 yaw，污染源会和搬迁问题搅在一起。

## 3. yaw 失真根因分析（调试总结 §20 的关键补充）

### 3.1 §20 二分方案的盲区

§20 的下一步是"Mahony 增益全置 0 走纯陀螺积分"。**但读码发现污染源候选不在 Mahony 里，而在桥接层的漂移补偿段**——把 Mahony 增益置 0 时它照常工作，实验会得出"纯陀螺积分也失真"的误导结论，把排查引向陀螺标度/积分链路（方向没错但多绕一圈）。

### 3.2 新嫌疑：漂移补偿把"旋转"误当"零偏"吸收（首嫌疑，机理推演）

`imu_bridge_update_filter` 的静止判据只用**加速度模值**：|a|−1g < 0.05g 即判"没动"。

- **绕竖直轴慢转时加速度模值 ≈ 1g** → 被判"静止" → 静止超 1s 后漂移跟踪启动，`g_gb_drift[z]` 以 0.02~0.05/采样 的速率向当前陀螺输出（= 旋转角速度 ω）收敛（时间常数 ≈ 2s）
- 收敛后修正角速度 = ω − ω ≈ 0 → **yaw 积分提前冻结** → 慢转 90° 只跟到一部分
- 停转后真实陀螺输出回 0，但 drift 仍记着 ω → 修正后输出 = −ω → **yaw 主动反向积分回落**，同时 drift 以 τ≈2s 重新收敛回 0，回落随之停止 → "回落到 ~0 后静置不漂"

**与症状吻合度**：慢转（~10s）90° 时理论跟随比例 ≈ τ/T ≈ 20% → **~18°，实测 16.5°/24.2°**；回落量 ≈ ω·τ ≈ 同量级回到 0。两个症状、一个机理，且解释了"halfez=0 复测无效"（污染源根本不是 Mahony 的 e_z 项）。

### 3.2.1 PC 仿真验证（已完成，2026-09-15）

`tools/imu_sim_verify.py`（纯 python 零依赖）逐行复刻固件流水线：imu_bridge 漂移补偿（静止判据/跟踪速率/修正）+ ImuFilter::mahony_filter（halfez=0，Kp=0.5）+ 四元数积分与欧拉角提取，10Hz 采样。场景：静稳校准 5s → 静置 5s → 匀速转 90° → 静置 15s。

| 组 | 场景 | 跟随角 | 静置 15s 后 | 回落量 |
|----|------|-----:|--------:|-----:|
| A1 现固件 | 慢转 10s（对照真机顺时针 16.5°） | **17.5°** | 0.5° | 17.0° |
| A2 现固件 | 较快转 5s（对照真机逆时针 24.2°） | **32.6°** | 1.1° | 31.5° |
| A3 现固件 | 极端慢转 14s | 12.6° | 0.4° | 12.2° |
| B1 E1 预演 | drift=off，慢转 10s | 90.0° | 90.0° | 0 |
| C1 修复 | 陀螺门限 1.5°/s，慢转 10s | **90.0°** | 90.0° | ~0 |
| C2 修复 | 陀螺门限 1.5°/s，较快转 5s | **90.0°** | 90.0° | ~0 |

**结论**：① A 组完整复现真机症状（跟随角落在实测区间、回落到 ~0）——§3.2 假说在数学上成立；② 修复方案（漂移跟踪加陀螺模值门限）跟随角 90°、零回落，且真静止时仍吸收零偏（长时漂移补偿能力保留）；③ 数学机理：漂移跟踪是时间常数 τ=Ts/rate（rate=0.05/0.1s → τ≈2s）的一阶低通，跟随角 ≈ 90°·τ/T_turn，回落量 ≈ ω·τ——两式给出的预测与仿真、真机三方吻合。

> 注意：仿真验证的是"机理可行性与修复方案正确性"（AGENTS §5.5 的 PC 级证据），**真机确认仍需 E1 实验**（IDRIFT 0 对照）才算硬件验证。

**标准修法方向**（预案，实验证实后再动手）：漂移跟踪的进入条件增加"陀螺模值门限"——|gf| 三轴均 < 门限（如 1.5°/s）才允许跟踪；旋转中不吸收，停止后只吸收真零偏。

### 3.3 其余候选（实验矩阵里逐一排除）

| 候选 | 机理 | 排除手段 |

## 4. 工具链设计

### 4.1 固件增量（全部可开关、默认关、不进控制路径）

| 命令 | 参数 | 功能 | 备注 |
|------|------|------|------|
| `ITEL 0/1` | — | IMU 遥测 CSV，默认 5Hz 分频可调 | 行：tick, gx, gy, gz(°/s×10), roll, pitch, yaw(°×10), 稳定标志, drift_z；STOP 联动关闭 |
| `IGAIN <kp100> <ki100>` | ×100 整数 | Mahony 增益在线整定 | 接通已存在的 `imu_bridge_set_mahony_gains()` |
| `IDRIFT 0/1` | — | 运行时漂移补偿开关 | **E1 实验的关键开关** |
| `IRATE <ms>` | 50/100/200 | IMU 更新周期可调 | 把 update 从 100ms 块改为独立节拍 |
| `ICAL` | — | 重新触发零偏校准（需静止） | 复位 cal_cnt + 四元数重初始化 |

解析逻辑进 `txt_cmd.c`（PC 桩可测），执行在 main.c 组装层（照 TEL/STEP 模式，注明对 C1/C4 的假设）。

### 4.2 PC 工具（tools/，纯 python + pyserial，复用 bt_connect 的端口存档）

| 脚本 | 用途 | 产出 |
|------|------|------|
| `imu_capture.py` | 采集 ITEL 流 → CSV | tools/data/imu_*.csv |
| `imu_turn_test.py` | **转 90° 协议化**：静置基线 → 提示转 90° → 静置观察回落 → 自动输出三指标 | 跟随角 / 回落角 / 漂移(°/min) + CSV |
| `imu_analyze.py` | 离线分析：gz 积分 vs yaw 输出对照（区分"陀螺侧丢角"还是"融合侧丢角"）、饱和检测、稳定窗检测 | 分析报告行 |

### 4.3 实验序列（二分法升级版，按序执行）

> **执行结果（2026-09-15 真机，VOFA+ FireWater 遥测）**：E1 基线 90° 只跟 -41.9° + 回落
> （回落速率 = driftz 值 -5.55°/s，机理铁证）→ **E1b `IDRIFT 0` 对照 -85.1° 满跟零回落**
> → 根因锁定 §3.2，门限修复（陀螺模值 <1.5°/s 才跟踪）已落地烧录。E2/E3 未需执行。
> ⬜ 剩：修复固件默认参数下复验（满跟 + 静置补偿保留）。

| # | 实验 | 操作 | 判读 |
|---|------|------|------|
| E1 | 漂移补偿隔离 | `IDRIFT 0` + 转 90° | 跟满且回落消失 → 根因锁定 §3.2 |
| E2 | Mahony 隔离 | E1 无效则 `IGAIN 0 0` + `IDRIFT 0` 纯积分 | 跟满 → Mahony 残余污染；仍丢 → 陀螺链路（标度/dt/量程） |
| E3 | 采样率 | `IRATE 50` 重测 | 改善明显 → 10Hz 漏角是叠加因素 |
| E4 | 量程/饱和 | ITEL 看快甩 raw | 贴 32767 → 提量程或软件限速 |

### 4.4 验证与收尾（照 AGENTS §5.4 闭环）

真机三指标（跟随角 ≈90°±10 / 回落角 <5° / 静置漂移 <1°/min）→ 修复回写默认 → 调试总结 §20 收口 → 开发跟踪 IMU-1/IMU-2 状态更新 → SOP 成文 → commit（数据 CSV 入库）。

## 5. 与 C3（姿态组件下沉）的关系

工具链落地并锁定根因**之后**再动 C3：届时漂移补偿/校准状态机搬进姿态组件，接口面板照 speed_loop 模板（注入 + tick 外部化 + PC 桩），搬完用 ITEL 曲线做搬迁前后等价比对（同 PID 工具链"C2 搬迁前后阶跃曲线比对"的做法）。
