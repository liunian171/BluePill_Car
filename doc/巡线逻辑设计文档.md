# BluePill_Car 巡线逻辑设计文档

## 0. 硬件前提

| 项目 | 参数 |
|------|------|
| 传感器数量 | 5 路灰度 (OUT1~OUT5 → S1~S5) |
| 黑线宽度 | **小于传感器间距**（居中时仅 S3 亮） |
| 传感器采样 | 二值 0/1，每 50ms 一帧 |
| 电机 | 左轮 M0/ENC0，右轮 M1/ENC1（M1 方向软件取反） |
| 巡航速度 | 30 RPM（串口 GS 可调） |
| 转弯速度 | 60 RPM（独立参数） |

```
传感器布局（俯视，车头向上）：
              前进方向 →
  S1(-2)  S2(-1)  S3(0)  S4(+1)  S5(+2)
    ●       ●       ●       ●       ●
    |       |       |       |       |
    |       |       |█████|       |
    |       |       |█████|       |   ← 黑线：居中仅 S3 可见
    |       |       |█████|       |
```

**位置公式**：`pos = (-2*S1 - S2 + 0*S3 + S4 + 2*S5) / sum`

**方向约定**：
- `pos > 0` → 黑线在车右侧 → 车偏左 → 需右转追线 → `corr > 0` → 左轮快、右轮慢
- `pos < 0` → 黑线在车左侧 → 车偏右 → 需左转追线 → `corr < 0` → 左轮慢、右轮快
- `corr` → PD 差速修正量，加到左轮、减到右轮

## 1. 传感器状态全集

### 1.1 稳定态（单传感器或模式稳定）

| 图案 | pos | 含义 |
|------|:---:|------|
| `00100` | 0 | 完美居中（仅 S3 亮） |
| `00010` | 1.0 | 偏左，黑线在 S4 |
| `01000` | -1.0 | 偏右，黑线在 S2 |
| `00001` | 2.0 | 严重偏左，黑线在 S5 |
| `10000` | -2.0 | 严重偏右，黑线在 S1 |

### 1.2 过渡态（两个传感器同时亮，黑线在之间）

| 图案 | pos | 含义 |
|------|:---:|------|
| `00110` | 0.5 | 黑线在 S3↔S4 之间，微偏 |
| `01100` | -0.5 | 黑线在 S2↔S3 之间，微偏 |
| `00011` | 1.5 | 黑线在 S4↔S5 之间，较偏 |
| `11000` | -1.5 | 黑线在 S1↔S2 之间，较偏 |

### 1.3 特殊态

| 图案 | pos | 含义 |
|------|:---:|------|
| `00000` | — | 全白，丢线/直角弯 |
| `11111` | 0 | 全黑，十字路口/粗线/异常 |
| `01010` | 0 | S2+S4 亮、S3 不亮，可能是噪声 |

### 1.4 传感器变化推断通用规则

| 变化 | 可推断信息 |
|------|-----------|
| S3: 1→0 | 正在脱离中心线；丢失程度取决于接下来谁亮 |
| S3: 0→1 | 正在回到中心线（修正生效的信号） |
| S2: 0→1 | 黑线往左移动（可能是车偏右，也可能是右转追线） |
| S2: 1→0 | 黑线离开左侧（车在回中，或车偏左了） |
| S4: 0→1 | 黑线往右移动（可能是车偏左，也可能是左转追线） |
| S4: 1→0 | 黑线离开右侧（车在回中，或车偏右了） |
| S2(0→1) 且 S4(1→0) | 确认正在从右侧往中心回移 |

### 2G. 震荡检测与收敛（三层阻尼机制）

振荡的根因：**回中时 corr 归零，但车轮差速惯性还在，继续推车头冲过中线**。

要收敛，必须让每次过冲的振幅比上一次小，最终稳定在 `00100`。三层机制叠加使用：

---

#### 第一层：回中瞬态反向阻尼（最关键）

| 条件 | 操作 |
|------|------|
| 检测到回中: `prev_s3==0 && cur_s3==1` 且 `g_action != 0` | `corr = -(上次 corr) × 0.5`，持续 **2 帧** |
| 2 帧后 | `corr = 0`，恢复正常 PD |

原理：不光 corr 归零，还要主动施加短暂反向差速抵消旋转惯性。

```
帧 N:   00010 (偏), g_action=+1, corr=+6 → 左轮比右轮快 6 RPM
帧 N+1: 00100 (回中!)
        → corr = -6 × 0.5 = -3 (反向阻尼) → 左轮比右轮慢 3 RPM
帧 N+2: 00100 (仍居中)
        → corr = -3 (反向阻尼继续)
帧 N+3: → corr = 0, 正常 PD
```

---

#### 第二层：逐次衰减系数 `g_decay`

每次检测到**过冲**（从一侧直接跳到另一侧，如 `00110 → 01100`），修正力度打对折：

| 事件 | 操作 |
|------|------|
| 过冲 (`00110→01100` 或 `01100→00110`) | `g_decay *= 0.5` |
| 稳定居中 20 帧（1 秒）以上 | `g_decay = 1.0`（恢复） |

修正公式变为：
```
corr = (Kp × pos + Kd × d_pos) × g_decay
```

效果：振荡次数越多，修正越轻，自然收敛。

```
第1次偏离: g_decay=1.0 → corr=6  → 回中 → 过冲
第2次偏离: g_decay=0.5 → corr=3  → 回中 → 微过冲
第3次偏离: g_decay=0.25 → corr=1.5 → 回中 → 基本停住
```

---

#### 第三层：死区迟滞（不轻易启动修正）

进出偏离都需要**连续 N 帧确认**，过滤边界抖动：

| 方向 | 条件 | 操作 |
|------|------|------|
| 启动修正 | 连续 2 帧不在 `00100` | 才启动 PD 修正 |
| 确认回中 | 连续 2 帧在 `00100` | corr 归零 + 反向阻尼 |

```
00100 → 00110 (单帧): 不动，标记"疑似偏右"
00110 → 00110 (连续): 确认偏离 → 启动修正

00110 → 00100 (单帧): 不动，标记"疑似回中"
00100 → 00100 (连续): 确认回中 → 归零 + 刹车
```

---

#### 收敛过程示例

```
帧0-3:  00100 (居中), g_decay=1.0, corr=0
帧4:    00110 (第1帧偏右), 不启动 (迟滞)
帧5:    00010 (第2帧偏右), 确认偏离 → 启动右转
         corr = 6 × 1.0 = +6, g_action = +1

帧6:    00110 (S3回来), 继续右转
帧7:    00100 (回中第1帧), 不归零 (迟滞)
帧8:    00100 (回中第2帧), 确认回中!
         → 反向阻尼 corr = -6 × 0.5 = -3, 持续 2 帧

帧9:    00100, 反向阻尼 corr = -3
帧10:   01100 (冲过头! 从右侧冲到左侧)
        过冲检测: g_decay = 1.0 × 0.5 = 0.5
        启动左转: corr = -6 × 0.5 = -3, g_action = -1

帧11:   01100, 继续左转
帧12:   00100 (回中第1帧), 不归零
帧13:   00100 (回中第2帧), 确认回中!
        反向阻尼 corr = +3 × 0.5 = +1.5, 持续 2 帧

帧14:   00100, 阻尼继续 +1.5
帧15-:  可能微偏到 00110
        g_decay=0.5 → corr = 6 × 0.5 = 3 (半力)
        很快拉回，稳定在 00100

帧16-35: 连续居中 20 帧 → g_decay 恢复到 1.0
✅ 收敛完成
```

```
    │  │    左直角: S5亮 (00001)            │  │
```

## 4. 直角弯判定（与追线丢线的区分）

### 4.1 核心原理

追线丢线的特征是 **S3 短暂丢失后可能回来**；
直角弯的特征是 **黑线从一侧边界全面消失，不会回来**。

因此直角 ≠ 看到 00000 就算，而是看 **00000 出现的前一刻图案**。

### 4.2 直角弯传感器路径

```
右直角（线往右消失）：
00100 → 00110 → 00111 → 00011 → 00001 → 00000
  ↑               ↑        ↑        ↑       ↑
 居中         一半全黑    S4+S5   仅S5   彻底消失

左直角（线往左消失）：
00100 → 01100 → 11100 → 11000 → 10000 → 00000
```

### 4.3 判别规则

| 00000 前一帧图案 | 判定 | 原因 |
|:---:|:---:|------|
| `00001` 或 `00011` 或 `00111` | ✅ **右直角** | 最后信号在右侧 |
| `10000` 或 `11000` 或 `11100` | ✅ **左直角** | 最后信号在左侧 |
| `00100` | ❌ 追线丢线 | 居中丢线，不是角 |
| `00110` 或 `01100` | ❌ 过渡态丢线 | PD追线中丢失 |
| `11111` | — 全黑 | 可能是十字路口，保持 corr=0 直行 |

### 4.4 转角方向 → 转弯执行

| 直角方向 | g_turn_dir | 转弯方式 |
|:---:|:---:|------|
| 右直角 | +1 | 左轮(M0)驱动, 右轮(M1)刹停 → 车以右轮为支点右转 |
| 左直角 | -1 | 右轮(M1)驱动, 左轮(M0)刹停 → 车以左轮为支点左转 |

## 5. TURNING 中的回正判定

转弯过程中传感器全白是**正常状态**，禁止超时进入 SEARCH。

### 5.1 右直角转弯回正路径

```
TURNING开始
    │
    ▼
全白 00000 (保持右转，外侧左轮 60 RPM)
    │
    ▼
10000 (S1 亮了！黑线从最左侧进来)
    │
    ▼
11000 (S1+S2 都亮了)
    │
    ▼
01100 (S2+S3 亮) 或 00100 (仅 S3) → ✅ 回正完成
```

### 5.2 左直角转弯回正路径

```
00000 → 00001(S5亮) → 00011(S4+S5) → 00110(S3+S4) 或 00100 → 回正
```

### 5.3 回正策略：退出 TURNING → FOLLOW 自然接管

**核心改变**：退出 TURNING 后不设盲刹（g_brake_cnt），直接让 FOLLOW 的传感器+PD 自然接管。PD 本身就是最优阻尼器——偏离越大修正越强，靠近中心自动衰减。

**退出条件**：任意传感器看到黑线（`g_sum > 0`）+ 已转弯 ≥ 500ms

```c
if (g_sum > 0 && (now_ms - g_tick > 500)) {
    spd_dir[0] = 1; spd_dir[1] = 1;
    g_state = LINE_FOLLOW;
    g_cool_end = now_ms + 800;
    // 不设 g_brake_cnt → FOLLOW 的 PD 自然接管
}
```

**退出后 FOLLLOW 逐帧行为（以右直角为例，CW 旋转，线从右边进入）**：

| 帧 | 传感器 | raw_pos | EMA | corr(RPM) | 车动作 |
|:--:|--------|:--:|:--:|:--:|------|
| 0 | `00001` | 2.0 | 1.2 | +9.6 | 强右转（同方向） |
| 1 | `00011` | 1.5 | 1.38 | +8.6 | 右转减弱 |
| 2 | `00110` | 0.5 | 0.85 | +4.0 | 轻右转 |
| 3 | `00100` | 0 | 0.34 | +1.0 | 微调 |
| 4 | `00100` | 0 | 0.14 | +0.4 | 基本停 |

PD 从 +9.6 自动衰减到 +0.4，5 帧内自然收敛。

**退出后 FOLLLOW 逐帧行为（以左直角为例，CCW 旋转，线从左边进入）**：

| 帧 | 传感器 | corr(RPM) | 车动作 |
|:--:|--------|:--:|------|
| 0 | `10000` | -9.6 | 强左转 |
| 1 | `11000` | -8.6 | 左转减弱 |
| 2 | `01100` | -4.0 | 轻左转 |
| 3 | `00100` | -1.0 | 微调 |
| 4 | `00100` | -0.4 | 停 |

**与直线 §1E 回中的关系**：转弯退出后走到 00100 时，FOLLOW 的 §1E 逻辑会检测到 `g_center_cnt≥2`，触发反向阻尼刹车。这和直线偏航回正完全一致，无需转弯专用代码。

**关键实现细节**：TURNING 中必须保持 `g_pos_prev = g_last_pos`，确保退出首帧 PD 的 d_pos 有效。

## 6. SEARCH 搜索模式

进入条件：
- FOLLOW 中 00000 但前一帧不符合直角条件（追线丢线）
- TURNING 中超时 3 秒找不到线

行为：
- 周期扫描：每 800ms 切换方向
  - 0~399ms：轻微右转（target[0]=80%base, target[1]=120%base）
  - 400~799ms：轻微左转（target[0]=120%base, target[1]=80%base）
- `g_sum > 0` → 任意传感器看到线 → 回 FOLLOW
- 4 秒超时 → 停车

---

## 7. LINE_EXIT 弯前刹车

进入条件：FOLLOW 中确认直角弯

行为：
- 两轮同时 `motor_bridge_brake`（短接制动）
- 持续时间 200ms
- 目的：消除直行惯性，避免带着动量进入转弯

200ms 后自动进入 TURNING。

---

## 8. 回正稳定

从 TURNING 或 SEARCH 回到 FOLLOW 后：
- 启动 800ms 冷却期
- 冷却期内禁止直角弯检测
- PD 正常工作追线
- 冷却期过后恢复正常巡线

```c

                               // 每帧根据 corr 符号更新

static uint8_t  g_state;      // LINE_FOLLOW/LINE_EXIT/LINE_TURNING/LINE_SEARCH

                               // 每次过冲 ×0.5, 稳定居中 1 秒恢复到 1.0

static uint8_t g_brake_cnt;   // 回中刹车剩余帧数 (0=不刹车)

/* ── 迟滞判定 ── */

static uint32_t g_00000_entry_tick;   // 进入 00000 的时刻

/* ── PD 参数 ── */
static float g_kp, g_kd;
static float g_base_spd, g_turn_spd;
static float g_pos_prev;

/* ── 00000 前一帧快照 ── */
// 当从非全白进入全白时，记录前一帧的传感器图案
// 用于判别"追线丢线"还是"直角弯"
```

## 12. 主循环时序

```
每 50ms (PID 周期):
  ├── line_follower_update(now, spd_target, spd_dir, enc0, enc1)
  │      ├── 读取传感器
  │      ├── EMA 平滑位置
  │      ├── 状态机决策 → 填充 spd_target[2], spd_dir[2]
  │      └── 更新 g_action
  │
  ├── PID 速度环 (每个电机):
  │      ├── spd_target[m] < 1.0 → skip
  │      ├── spd_dir[m] == 0 → pid_reset + motor_bridge_brake + continue
  │      ├── 编码器反算实际 RPM
  │      ├── pid_update(目标, 实际, dt) + 前馈
  │      └── motor_bridge_set_speed_rpm(m, pid_out * spd_dir[m])

每 100ms (显示周期):
  └── OLED 刷新 + 串口上报 VOFA+ 数据
```
